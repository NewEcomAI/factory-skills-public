# change-request-impact

Classify, size, and respond to a mid-project scope change in minutes.

## Install

```text
/plugin marketplace add NewEcomAI/factory-skills-public
/plugin install factory@factory-skills
```

## What you get

- Change-request classification and effort sizing
- An absorbability test against your remaining sprint capacity
- A dual output: an internal assessment record and a client-facing change-request email
- Your own response window and sender name — prompted inline when no process config is present

## Output

An internal record plus a ready-to-send client email stating the impact, the options, and the response window.
