# brand-spec-generator

Turn a short brand brief into a complete, accessible HTML design system spec.

## Install

```text
/plugin marketplace add NewEcomAI/factory-skills-public
/plugin install factory@factory-skills
```

## What you get

- A 13-section design system derived from your brief (3 adjectives, color direction, NOT-list)
- Color tokens and a type scale with WCAG 2.1 AA contrast checks
- A ready-to-paste cursor rules block
- Prompts for product name, personality adjectives, color direction, and the NOT-list when no brief is supplied

## Output

A full design-system spec (colors, typography, components, do/don't rules) plus a cursor rules export.
