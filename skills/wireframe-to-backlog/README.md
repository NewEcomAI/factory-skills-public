# wireframe-to-backlog

Turn a wireframe, mockup, or Figma/HTML prototype into a fully estimated development backlog.

## Install

```text
/plugin marketplace add NewEcomAI/factory-skills-public
/plugin install factory@factory-skills
```

## What you get

- A 5-pass read of your wireframe or prototype
- Epics and stories with hour estimates and sprint assignments
- A 4x correction factor automatically applied to infrastructure stories (auth, payments, billing, webhooks)
- Works with or without project config — prompts you for product name, stack, and infrastructure areas when none is present

## Output

A structured backlog: epics -> stories -> hour estimates -> sprint plan, ready to paste into your tracker.
